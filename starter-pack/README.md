# SURVIVAL JOURNEY — First Ember (starter browser game)
Playable standalone HTML: [Download from Google Drive](https://drive.google.com/file/d/1yZ3vElthHU5rx6qeuDC-KDCkX00fxN2w/view?usp=drivesdk) or use the downloadable conversation attachment `SURVIVAL_JOURNEY_STARTER.html`. The HTML bytes are stored on Drive under `LPM/`, **not yet committed as a GitHub source file**. **Download the file and double-click**; no CDN, bundler, Python/Node, or installation. Pure canvas software-rendered 3D polygons with isometric orthographic projection; this prototype deliberately does not require Three.js.

## Starter scene
- Small authored-style island, ocean rim; terrain expansion appears when purchased.
- Firepit research center and one wooden starter storage.
- Two original code-generated settlers Ada (female) and Bram (male), animated low-poly mesh bodies.
- Deer pack walking autonomously; gatherable berry shrubs, trees and small rock sites.
- Workers choose jobs autonomously, reserve resources, fetch required spear/axe from starter storage, perform timed action, carry yield to storage, earn AP **on successful delivery**, return tool; berry harvesting requires no knife.
- Click resources to mark priority. Click Firepit or use panel button to research.
- Firepit AP costs for Land Expansion, Tool Supply, Warehouse, Gather Skills and Fire Maintenance.
- Pan/zoom, pause, auto-AI toggle, notifications and live resource HUD.

## Important implementation boundary
This is an **offline executable gameplay prototype**, not the full asset pipeline. In-browser shapes are low-poly polygon meshes generated by JavaScript math and rendered with a compact orthographic software renderer on Canvas 2D. It is NOT Three.js, and it does not yet load the curated LPM GLBs or the exact uploaded animal/human concept-board geometry. That is the next asset-integration milestone.

The scene uses approximated stylized forms and minimal gait; it should be treated as a **gameplay mechanics test** not a visual QA pass for the curated starter pack. Terrain geometry also needs performance scaling and pathfinding/collision upgrades in the full engine.

## How to run
Save/open `SURVIVAL_JOURNEY_STARTER.html` in Chrome/Edge/Firefox. Press “Bắt đầu cuộc hành trình” to start. No web connection required. `R` opens Firepit; `Space` pauses; `Esc` closes panel.

### Acceptance checks
1. Start scene shows both settlers, deer, Firepit, warehouse, forest, berries and rocks.
2. Settlers claim individual nodes so multiple workers avoid claiming the same resource.
3. After hauling successful yield to storage, AP increases and a toast appears.
4. Click Firepit, purchase Island Expansion when AP >= 8; the island coastline expands and more forage nodes appear.
5. Primitive axe/spear requests are gated by available stock; gathering berries works without a knife.
6. Replay in offline browser with no CDNs; no automatic saving yet.

Repository's curated animal/human target specifications live in `starter-pack/STARTER_HUMANS_SPEC.md` and `STARTER_ANIMALS_SPEC.md` and their per-species `presets/`.
